# interfaz-construyete

## Proyecto: Hospital Web

Hospital Web es una página web estática desarrollada con HTML, CSS y JavaScript. Su objetivo es facilitar el acceso a la información y servicios relacionados con la atención médica, permitiendo a los usuarios conocer los servicios del hospital, consultar información y realizar solicitudes de citas médicas de manera sencilla.

## Descripción

El proyecto presenta una interfaz moderna con un portal de bienvenida, carga animada con barra de progreso, navegación entre secciones, explicación del sistema, roles, arquitectura (Cliente-Servidor), diagrama de flujo y un formulario para solicitar citas médicas.

## Tecnologías utilizadas

- **HTML5** – Estructura del sitio
- **CSS3** – Estilos, diseño responsive y animaciones
- **JavaScript Vanilla** – Interactividad y validaciones básicas

## Estructura del proyecto

```text
interfaz-construyete/

    └── Documentacion-Hospital-Web.pdf  # Documentación en PDF (pendiente imágenes)
```

## Secciones

1. **Inicio** – Explicación de qué es Hospital Web y cómo funciona.
2. **Roles** – Muestra los roles del sistema (Administrador, Cliente y Servidor).
3. **Arquitectura** – Expone los componentes, apartados y flujo Cliente-Servidor.
4. **Solicitar cita** – Formulario para registrar una solicitud de cita médica.

## Cómo visualizar el proyecto

Abre el archivo `index.html` directamente en cualquier navegador web (Chrome, Firefox, Edge, Brave, etc.).

No requiere servidor ni dependencias externas.
