🏥 Hospital Web

Sistema web para consultar y solicitar servicios médicos

🏥

¿Qué es Hospital Web?

Hospital Web es una página creada para facilitar el acceso a información y servicios relacionados con la atención médica.

¿Para qué sirve?
Esta plataforma permite conocer los servicios del hospital, consultar información y realizar solicitudes de citas de una manera sencilla.


¿Cómo funciona?
El usuario realiza una solicitud desde la página. La información puede ser procesada por un servidor y almacenada en una base de datos.

👥 Roles del sistema

👨‍💼

Administrador

Gestiona usuarios, citas, médicos y expedientes.

👤

Cliente

Consulta información y solicita citas médicas.

🖥️

Servidor

Procesa las solicitudes y administra la información del sistema.

🏗️ Arquitectura del sistema

👤 Usuario / Cliente

Es la persona que utiliza la página desde un celular, computadora o tablet.

📤 Solicitud

Es la petición que realiza el usuario, por ejemplo solicitar una cita médica.

🖥️ Servidor

Recibe las solicitudes y procesa la información del sistema.

📥 Respuesta

Es la información que el servidor devuelve al usuario.

🗄️ Base de datos

Contiene información de pacientes, médicos, citas y expedientes.

🔄 Flujo del sistema

Cliente → Solicitud → Servidor → Base de datos → Respuesta → Cliente.
